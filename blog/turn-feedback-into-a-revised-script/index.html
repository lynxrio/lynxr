How do you turn brand feedback into a revised script?

Turn brand feedback into a revised script by matching every note to the line it changes, making only those changes, and showing what moved and why. Ask one clear question about any note you cannot place, rather than guessing, so the next round is about the video and not about the notes.

Published 22 November 2026

What should you do first when the feedback arrives?

Read every note once without changing anything, then copy each one into its own line in a list so none gets lost.

Feedback can arrive as comments on a document, a long message, or a voice note, and the notes may not follow the order of the script. If you start editing at the first note, you may rewrite a line that a later note asks you to cut. A flat list fixes that, because you can see the whole picture before you touch a word. It also gives you something to tick off when you send the revision.

  • Number each note in the order it reached you, so you can refer to it later without quoting it in full.
  • Keep the brand's own words for each note. Paraphrasing at this stage can quietly change what was asked.
  • Mark any note that mentions wording the brand needs, such as a product name or a phrase it has to approve, because those are the ones you cannot reshape.
  • Put the original script beside the list, split into the parts in the parts of a UGC video script, so each note has a clear place to land.

How do you match each note to the line it changes?

Give every note a home in one part of the script, the hook, a beat, the turn or the close, and write down the change you will make there.

Some notes point straight at a line. Others describe a feeling, such as the video being slow or too salesy, and you have to find which line causes it. For a note about pace, look first at the hook and the first beat, because that is where a viewer decides to stay. For a note about tone, look first at the close. Write the change next to the note before you edit, so you can check the plan in one glance.

What do you do with a note you cannot place?

Ask one specific question about it before you revise, because a guess can cost you a whole extra round.

A note such as make it more fun or it needs more energy can point at the words, the delivery or the edit. Offer the brand a choice instead of an open question, so it can answer in one line. A short message works well: Hi [NAME], thanks for the notes on the [PRODUCT] script. On note [NUMBER], do you mean the wording of the opening line, or how I deliver it on camera? I can send the revised script by [DATE] either way. If two notes pull in opposite directions, that is a different problem, and handling feedback from two people at a brand covers it.

How do you send the revised script back?

Send the new script with a one-line reply to each note, saying what changed and where, so the brand can check it without comparing versions.

  • Put the changes where the brand can see them, for example in a different colour or with the old line struck through, because it saves them reading the whole script again.
  • Answer each numbered note in one line: what you changed and in which part.
  • Say plainly if you left a note out, and why, so it does not look as though you missed it.
  • Keep the earlier version, named clearly, in case the brand wants to go back to a line.
  • A two-column script makes this easier, because a note about a shot and a note about a line sit in different columns.

What if a note would weaken the script?

Make the change if the brand still wants it, but first explain briefly what it would cost and offer another way to get what the note is after.

A note asking for three more product points, for example, might push the product step so late that the payoff lands after a viewer has left. Say that, then offer a version: I can fit one of these into the turn and put the others in the caption, or I can add all three and trim the setup. Let the brand choose, and follow its answer. When the issue is length rather than content, cutting a script that runs long helps you decide what goes.
